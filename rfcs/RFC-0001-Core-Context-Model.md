# RFC-0001

## Title

Core Context Model

## Status

Accepted

---

# Abstract

This RFC defines the minimum conceptual model required by every PCP compliant project.

It defines concepts.

It does not define files.

It does not define directories.

It does not define implementations.

---

# Core Context Model

Every PCP project contains the following concepts.

## Identity

Project identity.

Examples:

- Name
- Purpose
- Scope
- Version

---

## Current State

Current development state.

Examples:

- Current objective
- Active work
- Recent progress

---

## Decision History

Architectural and technical decisions together with their rationale.

---

## Open Work

Incomplete work that requires future attention.

---

## Knowledge

Persistent project knowledge that should survive contributors, conversations and AI sessions.

---

## Architecture

System structure and important architectural information.

---

## Constraints

Technical, business and operational constraints.

---

## Operational Guide

Instructions that allow any contributor to continue work consistently.

---

# Compliance

A PCP implementation preserves every concept defined in this RFC.

How those concepts are stored is implementation specific.
