# Core Principles

1. Context First

2. Human Readable

3. AI Independent

4. Tool Independent

5. Living Documentation

6. Shared Understanding

7. Explicit Decisions

8. Continuity Over Memory

9. Implementation Independence

10. Open Evolution

## Stability Before Expansion

Once a specification element is accepted, it is considered stable.

Changes are introduced through new RFCs, not by rewriting accepted decisions.

Project history is preserved.
