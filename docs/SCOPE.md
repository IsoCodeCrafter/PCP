# Scope

## PCP Is

- An open specification
- A project context standard
- AI independent
- Tool independent
- Human readable
- Open for implementation

## PCP Is Not

- An AI framework
- A coding assistant
- A prompt collection
- A project management tool
- A Git replacement
- A workflow engine

## Reference Implementation

The `.context/` directory is the reference implementation of PCP.

It demonstrates the specification.

It is not the specification itself.
