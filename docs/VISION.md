# Vision

## Problem

Software projects gradually lose Project Context.

As context becomes fragmented, contributors repeatedly rediscover information instead of building on existing knowledge.

Project continuity should not depend on memory, conversations, or individual contributors.

---

## Vision

Establish an open, technology-independent standard for preserving, organizing, and transferring Project Context.

Enable projects to remain understandable and maintainable regardless of changes in contributors, AI systems, programming languages, development tools, or implementation technologies.

---

## Mission

Enable every contributor to continue a software project from a shared understanding rather than starting from fragmented or incomplete information.

Promote Project Continuity through standardized Project Context.

---

## North Star

**Standardizing Project Context to Preserve Project Continuity.**
