# PCP Reference Context Template

Welcome to the official Project Context Protocol (PCP) Reference Context Template.

This template provides a practical starting point for organizing and preserving Project Context.

Copy this directory into your project and maintain it as your project's single source of contextual information.

---

# Directory Structure

```text
context/

    DECISION_LOG.md
    KNOWLEDGE.md
    ARCHITECTURE.md
    OPERATIONAL_GUIDE.md
    OPEN_WORK.md
```

---

# Purpose of Each Document

## DECISION_LOG

Records significant project decisions.

Question answered:

> Why was this decision made?

---

## KNOWLEDGE

Records durable project knowledge.

Question answered:

> What should every contributor know?

---

## ARCHITECTURE

Describes the structure of the project.

Question answered:

> How is the project organized?

---

## OPERATIONAL_GUIDE

Documents operational procedures.

Question answered:

> How do we operate and maintain the project?

---

## OPEN_WORK

Tracks unfinished work.

Question answered:

> What still needs to be done?

---

# Usage

Maintain these documents continuously.

Do not wait until the end of the project.

Project Context is most valuable when it evolves together with the Project itself.

---

# PCP Compatibility

This template is designed for use with the PCP Specification.

Alternative organizations are acceptable provided they preserve the conceptual model defined by PCP.
