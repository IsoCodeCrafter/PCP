# Open Work

This document tracks unfinished work required to continue the evolution of the Project.

Record work that is planned, in progress, blocked, or awaiting a decision.

The purpose of this document is to ensure that unfinished work remains visible and understandable to every contributor.

---

# Work Item Template

## Identifier

```text
WORK-0001
```

---

## Title

```text
Short descriptive title
```

---

## Status

```text
Open
In Progress
Blocked
Completed
Cancelled
```

---

## Priority

```text
Critical
High
Medium
Low
```

---

## Description

Describe the work that needs to be completed.

Clearly define the expected outcome.

---

## Rationale

Explain why this work is important.

---

## Dependencies

Reference related items when applicable.

Examples:

```text
WORK-0004
DEC-0002
KN-0007
```

---

## Owner

Identify the current responsible contributor.

If no owner exists, record:

```text
Unassigned
```

---

## Target Version

Optionally specify the intended milestone or release.

Example:

```text
PCP 1.0
```
