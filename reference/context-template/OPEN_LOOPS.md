# Open Work

## Purpose

This document tracks unfinished work that requires future attention.

It provides continuity between contributors by making incomplete tasks explicit.

---

## When to Update

Update this document whenever:

- New work is identified.
- Existing work changes.
- Work is completed.
- Priorities change.

---

## Entry Format

### Title

Short description.

### Status

- Planned
- In Progress
- Blocked
- Waiting
- Completed

### Description

Detailed explanation.

### Related Context

Reference to decisions, architecture or other documents.

### Owner

Optional.

### Last Updated

YYYY-MM-DD
