# Simple Project Example

This example demonstrates the smallest practical implementation of the Project Context Protocol (PCP).

It represents a fictional project that uses the official PCP Reference Context Template.

The goal is to show how Project Context evolves during normal project development.

---

# Project

**Name**

TaskFlow

**Description**

TaskFlow is a lightweight task management application for small teams.

The application allows users to create, assign, and complete tasks.

---

# Project Context

This example contains the following Project Context documents:

* Decision Log
* Knowledge
* Architecture
* Operational Guide
* Open Work

Together, these documents describe the project beyond its source code.

---

# Learning Objectives

After reading this example, you should understand:

* how decisions are recorded
* how durable knowledge is preserved
* how architecture is documented
* how operational procedures are maintained
* how unfinished work is tracked

---

# Notes

This example intentionally remains small.

Larger examples demonstrate additional PCP capabilities.
