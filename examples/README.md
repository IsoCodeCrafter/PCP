# Examples

The examples in this directory demonstrate how the Project Context Protocol (PCP) can be applied to real projects.

They are intended to help contributors understand PCP by example before reading the full specification.

Each example represents a different level of complexity and a different collaboration model.

---

# Learning Path

We recommend exploring the examples in the following order.

## 1. Simple Project

A minimal project demonstrating the core concepts of PCP.

Recommended for first-time users.

Estimated reading time: **5 minutes**

---

## 2. AI Project

A project where humans and multiple AI systems collaborate using a shared Project Context.

Demonstrates how PCP preserves continuity across different contributors.

Estimated reading time: **15 minutes**

---

## 3. Enterprise Project

A large-scale project involving multiple teams, long-term maintenance, and organizational processes.

Demonstrates how PCP scales beyond individual projects.

Estimated reading time: **20 minutes**

---

# How to Use These Examples

1. Read the example.
2. Explore the Project Context documents.
3. Compare them with the PCP Specification.
4. Copy the Reference Template into your own project.
5. Adapt it to your workflow.

---

# Goal

These examples are not tutorials.

They are realistic reference projects designed to demonstrate how Project Context evolves throughout the lifecycle of a Project.

The objective is to help contributors understand **how PCP is used in practice**, not only **how it is specified**.
